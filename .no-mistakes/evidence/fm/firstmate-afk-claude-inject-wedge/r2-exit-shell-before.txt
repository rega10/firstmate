⏺ Auto mode lets Claude handle permission prompts automatically — Claude checks each
  tool call for risky actions and prompt injection before executing. Actions Claude
  identifies as safe are executed, while actions Claude identifies as risky are
  blocked and Claude may try a different approach. Ideal for long-running tasks.
  Sessions are slightly more expensive. Claude can make mistakes that allow harmful
  commands to run, it's recommended to only use in isolated environments. Shift+Tab
  to change mode.
